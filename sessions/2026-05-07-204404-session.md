  `CronCreate` but the runtime registered the job as session-only

  also covers this.

  session opens but Claude doesn't proactively re-schedule, that day's
  session log is missed but nothing else breaks. If misses become
  frequent, a launchd agent invoking `claude -p` headlessly is the more
  robust alternative.
